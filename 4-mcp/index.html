Part 4

Connect Claude Code to VERVE

This lets Claude Code read and change VERVE's test site as you, so you can ask it questions about the data. It takes about ten minutes. Do Parts 1 to 3 first.

  1. Install Claude Code, if you haven't

    Open Terminal (⌘ + Space, type Terminal, Return). Copy this, paste it, and press Return:

    curl -fsSL https://claude.ai/install.sh | bash

    Already have it? Skip this step. If it ends by telling you to run another line, copy and run that line too, then close Terminal and open it again.

  2. Add VERVE to Claude Code

    In Terminal, copy, paste and press Return:

    claude mcp add --transport http --scope user verve https://api.colab.riworks.app/api/mcp

    It should say it added the server. If it says already exists, that's fine.

  3. Start Claude Code in the project

    cd ~/colab-v2/verve-v2-api && claude

    The first time, it asks you to sign in to your Claude account and whether you trust the folder. Say yes.

  4. Sign in to VERVE from Claude

    Type /mcp and press Return. Use the arrow keys to pick verve, then Authenticate.

    A browser page opens. Sign in with your coLAB email the same way as Part 3, then click Approve. Come back to Terminal; it should show verve as connected. Press Esc to close the list.

  5. Test it

    Copy this, paste it into Claude, and press Return:

    Use the verve tools to tell me who I am signed in as and which organizations I can see.

    Claude asks before using each tool. Choose Yes. It should answer with your name and a list that includes coLAB, PANO and the two sample clients.

  6. Send Ken a screenshot

    Press ⌘ + Shift + 4, then Space, and click the Terminal window, so Ken can see Claude's answer.

    If any step stops with an error, send a screenshot of that instead.

What did this just do?

MCP is how Claude connects to another system. Adding VERVE gives Claude a set of tools, one for each thing the site can do: list organizations, read a plan, save answers, and so on.

Claude uses them as you, with your access and nothing more. Every call it makes is recorded with your name. To disconnect, type /mcp, pick verve, and choose to clear the sign-in.

Questions: ask Ken.
