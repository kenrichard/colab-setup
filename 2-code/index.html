Part 2

Get the code

This downloads the coLAB project to your Mac, so Claude Code can read it. It takes a minute or two. Do Part 1 first.

  1. Copy the command

    curl -fsSL https://raw.githubusercontent.com/kenrichard/colab-setup/main/get-code.sh | bash

  2. Open Terminal and paste it

    Press ⌘ + Space, type Terminal, and press Return. Click in the window, press ⌘ + V to paste, then press Return.

    If it says Ken needs to add you, send him the screenshot. It shows your GitHub username, which is what he needs. Run it again once he says you're in.

  3. Send Ken a screenshot

    When it says All done, press ⌘ + Shift + 4, then Space, and click the Terminal window. The screenshot lands on your desktop.

    If it stops with an error, send a screenshot of that instead. It's safe to run again.

What does this download?

Two folders, inside a new colab-v2 folder in your home folder:

  • verve-v2-api holds the data, the rules for who can see what, and every planning document.
  • verve-v2-colab holds the screens people use.

Both are private. Running the command again later fetches the latest changes.

You can read the script before running it.
