Part 2

Install Claude Code and get the code

This installs Claude Code, then has it download the coLAB project to your Mac. It takes about ten minutes. Do Part 1 first.

  1. Install Claude Code

    Open Terminal (⌘ + Space, type Terminal, Return). Copy this, paste it, and press Return:

    curl -fsSL https://claude.ai/install.sh | bash

    Already have it? Skip this step. If it ends by telling you to run another line, copy and run that line too, then close Terminal and open it again.

  2. Start Claude Code in a new colab-v2 folder

    mkdir -p ~/colab-v2 && cd ~/colab-v2 && claude

    The first time, it asks you to sign in to your Claude account and whether you trust the folder. Say yes.

  3. Ask Claude to get the code

    Copy this, paste it into Claude, and press Return:

    Use gh to clone colab-verve/verve-v2-api and colab-verve/verve-v2-colab into this folder. If I do not have access to them, tell me my GitHub username so I can send it to Ken.

    Claude asks before running each command. Choose Yes.

    If Claude says you don't have access, send Ken the screenshot. It shows your GitHub username, which is what he needs. Ask Claude again once he says you're in.

  4. Send Ken a screenshot

    When Claude says both are downloaded, press ⌘ + Shift + 4, then Space, and click the Terminal window. The screenshot lands on your desktop.

    Type /exit and press Return to leave Claude.

What does this download?

Two folders, inside the new colab-v2 folder in your home folder:

  • verve-v2-api holds the data, the rules for who can see what, and every planning document.
  • verve-v2-colab holds the screens people use.

Both are private. Later, you can ask Claude to get the latest changes.

Questions: ask Ken.
