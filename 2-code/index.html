Part 2

Get the code with Claude

This has Claude download the coLAB project to your Mac, using the Claude desktop app. It takes about ten minutes. Do Part 1 first.

  1. Open the Claude app

    If you don't have it, download it from claude.ai/download, install it, and sign in.

    The coding part of the app needs a paid Claude plan: Pro, Max, Team or Enterprise. If clicking Code in the next step asks you to upgrade, tell Ken.

  2. Start a coding session in a new colab-v2 folder

    Click Code at the top of the window. In the box at the bottom, choose Local, then click Select folder.

    In the window that opens, go to your home folder (the one with your name, under Locations or on the left). Click New Folder, name it colab-v2, and click Open.

  3. Ask Claude to get the code

    Copy this, paste it into the box, and press Return:

    Use gh to clone colab-verve/verve-v2-api and colab-verve/verve-v2-colab into this folder. If I do not have access to them, tell me my GitHub username so I can send it to Ken.

    Claude asks before running each command. Allow it.

    If Claude says you don't have access, send Ken the screenshot. It shows your GitHub username, which is what he needs. Ask Claude again once he says you're in.

  4. Send Ken a screenshot

    When Claude says both are downloaded, press ⌘ + Shift + 4, then Space, and click the Claude window. The screenshot lands on your desktop.

What does this download?

Two folders, inside the new colab-v2 folder in your home folder:

  • verve-v2-api holds the data, the rules for who can see what, and every planning document.
  • verve-v2-colab holds the screens people use.

Both are private. Later, you can ask Claude to get the latest changes.

Questions: ask Ken.
