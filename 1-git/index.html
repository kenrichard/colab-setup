Part 1

Install git and connect to GitHub

This installs the tools Claude Code needs: git, the GitHub tools and Node. It takes 15–45 minutes, mostly waiting for downloads.

  1. Copy the command

    curl -fsSL https://raw.githubusercontent.com/kenrichard/colab-setup/main/setup-mac.sh | bash

  2. Open Terminal and paste it

    Press ⌘ + Space, type Terminal, and press Return. Click in the window, press ⌘ + V to paste, then press Return.

  3. Follow what it says

    Keep the laptop plugged in and the lid open. Along the way it will:

    • Ask for your Mac password once. Nothing appears on screen while you type it. That's normal. Type it and press Return.
    • Ask for your name and email.
    • Have you sign in to GitHub in your browser. If you don't have an account, make one at github.com first.

  4. Send Ken a screenshot

    When it says All done, press ⌘ + Shift + 4, then Space, and click the Terminal window. The screenshot lands on your desktop.

    If it stops with an error, send a screenshot of that instead. It's safe to run again; it skips whatever is already done.

  5. Restart Claude

    Quit the Claude app with ⌘ + Q and open it again, so it finds the new tools.

What does this install?

Git keeps a history of every change to the code and makes it possible to undo changes. GitHub is the website where the coLAB code is shared. Claude Code needs both.

In order, the script installs Apple's Command Line Tools (which include git), Homebrew (which installs the rest), the GitHub command-line tool, and Node. Then it records your name for git and signs you in to GitHub.

You can read the script before running it.
