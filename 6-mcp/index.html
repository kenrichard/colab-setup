Part 6

Connect Claude to VERVE

This lets Claude read and change VERVE's test site as you, so you can ask it about the data in an ordinary chat or while coding. It takes about five minutes. Do Part 3 first. It doesn't need the token from Part 4.

  1. Add VERVE as a connector

    In the Claude app, go to Customize › Connectors and click Add custom connector. Copy this address into the URL box:

    https://api.colab.riworks.app/api/mcp

    Name it VERVE if it asks for a name. Leave everything else as it is and click Add.

    No Add custom connector button? Your Claude account is probably part of a team, where only the owner can add connectors. Tell Ken. Once the owner adds it, you'll find VERVE in the same list and can go on to the next step.

  2. Sign in to VERVE

    Click Connect beside VERVE. A browser page opens. Sign in with your coLAB email the same way as Part 3, then click Approve.

  3. Test it

    Start a new chat. Copy this, paste it, and press Return:

    Use VERVE to tell me who I am signed in as and which organizations I can see.

    Claude may ask before using VERVE. Allow it. It should answer with your name and a list that includes coLAB, PANO and the two sample clients.

  4. Send Ken a screenshot

    Press ⌘ + Shift + 4, then Space, and click the Claude window, so Ken can see the answer.

    If any step stops with an error, send a screenshot of that instead.

What did this just do?

A connector gives Claude a set of tools for another system. VERVE's tools match what the site can do: list organizations, read a plan, save answers, and so on. The connector works in chats and in coding sessions.

Claude uses them as you, with your access and nothing more. Every call it makes is recorded with your name. To disconnect, go back to Customize › Connectors and remove VERVE.

Questions: ask Ken.
