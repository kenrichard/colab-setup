Getting set up for coLAB

These steps get your Mac ready to work on the coLAB project with the Claude desktop app. Do them in order, one at a time. Each one ends with a screenshot to send Ken.

  1. 1 Install git and connect to GitHub One command. 15–45 minutes, mostly downloads.
  2. 2 Get the code with Claude In the Claude app. About ten minutes.
  3. 3 Sign in to VERVE In your browser. A few minutes.
  4. 4 Get a token In your browser. Two minutes. Do Part 5 straight after.
  5. 5 Run VERVE's screens on your Mac Using the test site's data. About ten minutes.
  6. 6 Connect Claude to VERVE In the Claude app. About five minutes.
Questions: ask Ken.
