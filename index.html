Getting set up for coLAB

These steps get your Mac ready to work on the coLAB project with Claude Code. Do them in order, one at a time. Each one ends with a screenshot to send Ken.

  1. 1 Install git and connect to GitHub One command. 15–45 minutes, mostly downloads.
  2. 2 Get the code One command. A minute or two.
  3. 3 Sign in to VERVE In your browser. A few minutes.
  4. 4 Connect Claude Code to VERVE A few commands. About ten minutes.
Questions: ask Ken.
